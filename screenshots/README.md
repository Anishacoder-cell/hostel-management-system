# Hostel Management System Screenshots

This folder contains screenshots demonstrating the functionality of the Hostel Management System developed using Java.

## Application Screenshots

### 1. Main Menu
Displays the main menu and available system operations.

### 2. Student Registration
Shows how new students are registered into the system.

### 3. Room Management
Displays hostel room information and management options.

### 4. Room Allocation
Demonstrates how rooms are allocated to registered students.

### 5. Payment Processing
Shows how student payments are recorded.

### 6. Payment Receipt
Displays the receipt generated after a successful payment.

## Purpose

These screenshots provide visual evidence of the system's implementation and demonstrate its major functionalities.
